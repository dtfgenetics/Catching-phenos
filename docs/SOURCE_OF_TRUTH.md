# PhenoQuest: The Living Seed Vault — Source of Truth

`dtfgenetics/Catching-phenos` is the canonical preproduction repository for PhenoQuest: The Living Seed Vault. It owns the game bible, structured system/data schemas, technical planning, and future browser implementation.

Google Drive `04 Games/Catching Phenos` is canonical for approved human-readable design masters, original artwork/source assets, playtest evidence, proofs, and approved release packages.

## Current state

Status: **canonical preproduction**. The repository is intentionally design/data-first. Do not treat it as a production game until the MVP systems, roster, technical plan, playable build, and release checks are complete.

## Identity/IP rule

PhenoQuest must remain an original cannabis genetics adventure. Do not use Pokémon names, slogans, logos, characters, fonts, capture-ball concepts, copied battle layouts, or public-facing catchphrases associated with that franchise.

## Release

A release requires locked MVP systems, validated Pheno/move/item/quest/encounter/expression data, playable browser behavior, original approved assets, playtest evidence, and a separated approved release package in Drive.
